# Source and review use

Materials are supplied for scholarly peer review and numerical reproduction.
The authors can attach the final public reuse license in the deposit metadata.
Third-party dependencies retain their own licenses. Bibliographic authors in
code/documents identify cited work rather than the authors of this submission.

Original receiver recordings are distributed by their providers:

- CTTC / GNSS-SDR: https://gnss-sdr.org/my-first-fix/
- TEXBAT: https://radionavlab.ae.utexas.edu/texbat/

This package distributes derived scores and events, not those raw recordings.
The analysis uses only supplied files. Original source paths in provenance
refer to relative repository locations; user/home paths are replaced with
generic tokens. Reference implementations retain historical directory layouts.
The archive contains no Git history, credentials, author contact details,
Word author metadata or operating-system ownership metadata.
